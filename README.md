# 📊 Global Trend Analyst

A high-performance financial dashboard designed for institutional-grade stock analysis and forensic auditing.

### 🚀 Key Features:
- **Technical Intelligence:** Live Candlestick charts with RSI and MACD subplots.
- **Fundamental Scoring:** Algorithmic "Buy/Hold/Sell" signals based on P/E, EPS, and Debt-to-Equity ratios.
- **Forensic Auditor:** Scans 100+ page Annual Reports (PDF) for legal and financial red flags using heuristic sentiment analysis.
- **Global Operations:** Real-time market status tracking for NSE, NYSE, LSE, SSE, and more.

### 🛠️ Tech Stack:
Built with **Streamlit**, **YFinance**, **Plotly**, and **PyMuPDF**.
